# Preventivi.Web

Applicazione Web per la gestione del ciclo completo di preventivazione.

## Tecnologie

- ASP.NET Core
- Razor Pages
- SQL Server
- ADO.NET
- Bootstrap

## Struttura repository

- `src` - codice sorgente
- `database` - script SQL e migrazioni
- `docs` - documentazione
- `tools` - utility di sviluppo

## Stato

Progetto in fase iniziale di sviluppo.
